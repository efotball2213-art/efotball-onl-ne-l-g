# AGENTS.md

eFootball league site (Turkish UI): live standings, top scorers (gol krallığı), recent matches, and a password-protected admin panel. Dark theme with gold palette.

## Tech Stack

TanStack Start (React 19, file routes) · Tailwind CSS 4 (theme vars in `src/styles.css`) · Netlify Database via `@netlify/database` + Drizzle ORM (`drizzle-orm@beta`) · lucide-react icons · sonner toasts.

## Structure

```
db/schema.ts                     # teams, scorers, matches, settings (key/value)
db/index.ts                      # drizzle client (drizzle-orm/netlify-db)
netlify/database/migrations/     # generated by `npx drizzle-kit generate --name <name>`; never edit applied ones
src/lib/league.ts                # shared types, computeStandings(), form labels
src/lib/diff.ts                  # diff between two league snapshots (for flashes/sounds on live updates)
src/lib/sounds.ts                # Web Audio synthesized sound effects + mute state (localStorage)
src/hooks/use-live-league.ts     # polls getLeagueVersion every 3s, refetches on change
src/server/auth.server.ts        # admin password check + HMAC-signed session token
src/server/league.server.ts      # all DB reads/writes; every mutation calls bumpVersion()
src/server/league.functions.ts   # createServerFn wrappers; validate input, requireAdmin(token)
src/components/league/           # public UI (standings w/ FLIP reorder, podium, matches, particles, confetti)
src/components/admin/            # admin login + panels (teams, match, scorers, settings)
src/routes/index.tsx             # public home
src/routes/admin.tsx             # admin panel
public/img/hero-trophy.png       # AI-generated hero; always served via /.netlify/images
```

## Key decisions

- **Live updates** use lightweight polling: `settings.version` (timestamp) is bumped on every mutation; clients compare it and refetch everything only when it changes.
- **Standings stats are stored directly on teams** (W/D/L/GF/GA/pointsAdjust/form) so the admin can edit them by hand. Adding a match increments both teams; deleting a match reverses it. Points = W×3 + D + pointsAdjust, computed client-side in `computeStandings`.
- `form` is stored as `W/D/L` (newest first, max 5) and displayed as Turkish `G/B/M`.
- **Auth**: password from `ADMIN_PASSWORD` env (falls back to the owner's chosen default). Token = `expires.hmac`, stored in localStorage, sent with every admin server function; no user accounts.
- Sounds only play after the first user interaction (browser autoplay policy).
- Single dark theme: `<html class="dark">`, `:root` holds dark gold values. Custom utilities: `.text-gold`, `.bg-gold`, `.btn-gold`, `.border-gold-gradient`, `.glass`, plus animation classes (`fade-up`, `pop-in`, `row-flash`, …).

## Conventions

- All user-facing copy is Turkish.
- Read `localStorage` only inside effects (SSR).
- Schema change → update `db/schema.ts` → `npx drizzle-kit generate --name <verb_noun>`.
